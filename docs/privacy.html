Privacy policy

Last updated: 25 November 2026

Short version: PanelSim collects nothing. There is no account system, no telemetry, no analytics and no advertising — in the app or on this site.

The desktop app

PanelSim runs entirely on your computer. It makes no network requests after download. Your projects are plain local files; nothing about them is uploaded, and there is no server that could receive it. The app sets no cookies and uses no tracking of any kind.

This website

This site is a set of static files hosted on GitHub Pages. It sets no cookies and runs no analytics or advertising scripts. Like any web server, GitHub processes standard request data (such as IP address and browser user-agent) in security logs to operate the service.

Downloads

Installers and portable builds are served by GitHub Releases, which processes the same standard request data for security and delivery.

Processors

GitHub, Inc. — hosting for this site and the release files. That is the complete list. If that ever changes, this page will be updated before any new processing begins.

Contact

Questions? Open an issue at github.com/243275-ctrl/panel-sim.
